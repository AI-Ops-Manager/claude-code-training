# ドキュメント更新スキル

## やること
プロジェクトのドキュメントを作成・更新する。

## ルール
1. ドキュメントはすべて `docs/` ディレクトリに配置する
2. 新規作成・更新時は必ずファイル先頭にメタデータを記載する：
   ```
   # タイトル
   - 作成日: YYYY-MM-DD
   - 更新日: YYYY-MM-DD
   - バージョン: v1.0
   ```
3. 更新時はバージョンを上げる（v1.0 → v1.1）
4. 更新内容を簡潔にファイル内に記録する
5. 大きな変更（機能追加・構造変更）はメジャーバージョンを上げる（v1.x → v2.0）

## 手順
1. 対象のドキュメントを確認する（なければ新規作成）
2. 変更内容をユーザーに確認する
3. ドキュメントを更新する
4. メタデータ（更新日・バージョン）を更新する
5. 変更内容をユーザーに報告する
