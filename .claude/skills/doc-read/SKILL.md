# ドキュメント読み込みスキル

## やること
プロジェクトのドキュメントを読み込んで、現在の状態を把握する。

## 手順
1. `docs/` ディレクトリの一覧を確認する
2. 各ドキュメントの更新日・バージョンを確認する
3. 最新のドキュメントから順番に読む
4. プロジェクトの現状をユーザーに簡潔に報告する：
   - 何が完了しているか
   - 何が進行中か
   - 次にやるべきことは何か

## 出力フォーマット
```
## プロジェクト現状
- 完了: ...
- 進行中: ...
- 次のアクション: ...
- 最終更新: YYYY-MM-DD
```
